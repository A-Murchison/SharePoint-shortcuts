# SharePoint Shortcuts
Marcadores de SharePoint que ejecutan JavaScript para realizar acciones útiles.

## Configuración

Hay dos formas de comenzar. Podemos crear una página en la barra de marcadores o crear un fragmento de código (code snippet). Lo que mejor funcione para usted.

### Barra de marcadores
Agregue una nueva página a la barra de marcadores y añada el JavaScript en el campo de la URL.

![image](https://github.com/A-Murchison/SharePoint-Shortcuts/assets/17418214/38d21787-ab2c-499a-a66b-51daffbbb061)

### Fragmentos de código (Code snippets)
[Crear un snippet](https://learn.microsoft.com/en-us/microsoft-edge/devtools-guide-chromium/javascript/snippets#create-a-new-snippet)

## Obtener Nombre Interno - getInternalName.min.js
Obtiene el nombre interno de una columna en una lista.

En la siguiente captura de pantalla, puede ver que la columna con el nombre visible 'Test' tiene el nombre interno 'Test_x0020_Column'.

![image](https://github.com/A-Murchison/SharePoint-Shortcuts/assets/17418214/b1d4904e-e217-4523-894a-f807abfca80e)

## Obtener Bolsa de Propiedades del Sitio - getSitePropertyBag.min.js
Obtiene los valores XML de la bolsa de propiedades (property bag) del sitio actual y los muestra en la consola. Por lo general, esto no cabe en el 'prompt()' de JavaScript en todos los navegadores, por lo que simplemente lo coloco en la consola.
